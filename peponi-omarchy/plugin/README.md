# Peponi One Day — Omarchy plugin

Part of the **peponi-omarchy** helper. Install from the parent folder:

```bash
cd ..
./scripts/install.sh
```

| | |
|---|---|
| **Plugin id** | `peponi.one-day` |
| **Kinds** | `service`, `overlay`, `bar-widget` |
| **Data** | Live via `peponi` CLI → peponi.to `/api/v1` (paid accounts) |

## In-overlay keys

`←`/`→` day · `y` Not Yet · `t` today · `Esc` close · `?` help

## Global (optional)

`SUPER+ALT+O` toggle · `SUPER+ALT+LEFT/RIGHT` days · `SUPER+ALT+Y` drawer

See [../README.md](../README.md) and [TESTING.md](TESTING.md).
